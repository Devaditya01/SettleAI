Terms &
Conditions.

These terms describe the intended use and limitations of the SettleAI demo.

01 / Using the demo

SettleAI is a prototype for exploring settlement support workflows. You can use the demo to test sample transactions, inspect evidence, and export sample reports. It does not process payments or move money.

02 / Sample data

All transactions, customers, bank outcomes, and ledger entries shown in the demo are synthetic. Dates and balances describe fixed sample scenarios, not current financial activity.

03 / Answers and limitations

Answers use local rules and sample records. They are not confirmation of a real settlement or a promise of a payout. For an actual payment, verify the outcome with your payment provider and bank.

04 / Information you enter

Use sample transaction IDs only. Do not enter passwords, API keys, bank account details, or real customer information. This version processes demo questions in your browser and stores your theme preference locally. Hosting services may separately receive standard web request information.

05 / Project information

Features and sample scenarios may change as the project develops. Visit the SettleAI repository for the source code and project updates.
