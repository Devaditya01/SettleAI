# Settle landing pages — Midnight & Pearl

Two original landing-page directions inspired by the supplied brand-campaign references: restrained monochrome palettes, oversized editorial type, and brushed-metal sculptural imagery. The reference screenshots are not embedded or republished.

## Open

- `index.html` — Midnight: charcoal, champagne, and warm silver.
- `pearl.html` — Pearl: ivory, graphite, and pale metal.
- Both link to the existing demo at `../index.html`.

Open either HTML file in a modern browser. Keep the folder structure intact. No installation, network connection, API key, or build step is required. Links to GitHub require internet access.

## Motion

- Brief brand entry transition.
- Staggered headline reveal and viewport-based section reveals.
- Slow floating artwork with pointer-responsive parallax.
- Magnetic calls to action and a tilting investigation card.
- Animated evidence path and selectable source explanations.
- An interactive four-step settlement case.
- Scroll progress, counters, continuous type strip, and sculptural orbit loops.
- Native reduced-motion support plus a footer motion toggle.
- Mobile navigation, keyboard controls, and accessible native dialogs.

The hero sculpture uses an original raster image with CSS transforms. It is not a live WebGL model. Visible counters describe the existing twelve-transaction synthetic demo and do not imply production benchmarks. Login, a live AI model, payment processing, and data integrations are outside the prototype.
